## YouTube description
What's the first system every business should build? This one's easy: a CRM.

When I started Aspire, I had never used a CRM before, so naturally I didn't use one at first. Then as the business grew, any time I needed data about the business - a revenue figure, any simple number - I'd have to go to Excel and seven other places and compile it. It would take an hour to answer a basic question about my own company.

So we built a CRM, and it took a really long time - partly because the business had already grown so much, and partly because I was learning how to use one at the same time. The longer you wait, the harder the build gets.

Start on day one. It will save you so much time over the long run.
